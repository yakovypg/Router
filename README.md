# Router

A request router for C# that maps URL-like paths to handler delegates using templates with static and typed dynamic segments.

## Requirements

- .NET 10 SDK

## Project Layout

- `Core/RouterCore` — the router library
- `Applications/RouterApp` — demo console app
- `Tests/RouterTests` — xUnit tests

## Run Application

```bash
dotnet run --project Applications/RouterApp
```

## Run Tests

 ```bash
dotnet test
 ```
